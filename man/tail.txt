NAME
    tail - show the end of a file

SYNOPSIS
    tail [-f] [-n N] <file>
    tail -N <file>

DESCRIPTION
    Shows the last 10 lines of a file, or the last N. With -f it then
    keeps watching the file and shows lines as they are added, until you
    press Ctrl+C; if the file is replaced (as when a log rolls over), it
    starts again from the top of the new one.

OPTIONS
    -n N      show the last N lines (up to 256)
    -f        follow: keep showing new lines until Ctrl+C

EXAMPLES
    tail -n 20 notes.txt
    tail -f ~/.sshd/logs/sshd.log
