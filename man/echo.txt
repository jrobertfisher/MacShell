NAME
    echo - print text

SYNOPSIS
    echo [text ...]

DESCRIPTION
    Prints its arguments separated by spaces. With > or >> it writes the
    text to a file; files written this way have Mac (CR) line endings,
    so SimpleText shows them properly.

EXAMPLES
    echo Hello
    echo "first line" > notes.txt
    echo "another line" >> notes.txt

SEE ALSO
    cat, macshell
