NAME
    entropy - show the randomness gathered

SYNOPSIS
    entropy

DESCRIPTION
    SSH and HTTPS need unpredictable random numbers, which classic Mac
    OS doesn't provide. Secure connections need 256 bits. They come
    from mouse movement and keystrokes the first time (MacShell asks),
    then from a seed file saved by each run, which is used up when read.
    Sound input noise and clock jitter are always mixed in and health
    tested, but not counted, since mains hum on an idle input can look
    random. entropy shows what each source gave.
