NAME
    cut - pick fields from each line

SYNOPSIS
    cut -d<delimiter> -f<fields> <file>

DESCRIPTION
    Prints chosen fields of each line, where fields are separated by
    delimiter. fields is a list such as 1,3 or a range such as 2-4.

OPTIONS
    -d<c>     the character between fields (default: tab)
    -f<list>  which fields to print, counting from 1

EXAMPLES
    cut -d, -f1,3 data.csv
    cut -d: -f2-4 list.txt

SEE ALSO
    grep
